## Why AGPL

`third_party/n64flashcartmenu/boot/` provides the IPL2→IPL3 handoff — CIC
fingerprinting, RCP quiesce, and the trampoline that gives the CPU to the
target ROM. It is AGPL-3.0 with no linking exception, so the combined `.z64`
is a derivative work and the whole project takes that licence. This was not
chosen from a menu; it is what the dependency requires.

AGPL section 13 (the network clause) has nothing to act on in a cartridge
ROM, so in practice these terms behave as GPL-3.0: distribute a modified
build and you must offer complete corresponding source.

If you need a permissive licence, the boot handoff is the only thing standing
in the way — about 1,700 lines reached through a single call site in
`src/rom_boot.c`. `third_party/n64flashcartmenu/VENDORED.md` explains what
reimplementing it would cost. The CIC checksum tables are the hard part.

## Why `data/` is licensed separately

`data/coverdb.csv` is derived from the libretro-database Nintendo 64 DATs,
which are CC BY-SA 4.0 — a share-alike licence. Creative Commons has declared
exactly two outside licences ShareAlike-compatible with version 4.0: the Free
Art License 1.3 and GPLv3. **AGPLv3 is not among them.** Rather than assert a
compatibility nobody has declared, those files keep their upstream licence and
carry their own `data/LICENSE`. They are read by host-side tooling at build
time and are not linked into the ROM.

## `src/rom_db.c`

Generated by `tools/build_rom_db.py` from the save-type table in the ares
emulator (`mia/medium/nintendo-64.cpp`), which is ISC. ISC is permissive and
composes with AGPL; its notice is retained in the file header. Regenerate it
rather than editing it by hand.

## The font

The interface font is [Spleen](https://github.com/fcambus/spleen) 5x8, kept
as its BDF under `third_party/spleen/` and rasterised into a sprite at build
time by `tools/build_compact_font.py`. BSD-2-Clause composes with AGPL; the
licence text travels with the file, and the built ROM carries the glyphs.

## Box art

None is included in the repository or in a release, and none should be added.
Cover images belong to their publishers and are not yours or ours to relicense
— a permissive licence stamped over scanned box art is void as applied,
whoever does it.

The prep tool fetches nothing. It reads the
[n64-flashcart-menu-metadata](https://github.com/n64-tools/n64-flashcart-menu-metadata)
collection — the public-domain (Unlicense) set the N64FlashcartMenu and the
EverDrive-64 Pro's own menu draw on — from wherever the user has put it on the
card, and converts the boxes their library needs. That is the line this
project holds: it never distributes a picture, never downloads one, and never
claims a licence over one. The collection's dedication covers its own
contribution; the scans themselves remain the publishers'. A card prepared
with the tool carries them the way a card prepared for either of those menus
does; passing that card on is the user's act, not ours.
